# MDE-POS: Local XAMPP (MySQL) Installation & Supabase Cloud Synchronization Guide

## Architecture Overview

MDE-POS implements an **Offline-First / Local-First Multi-Tier Architecture**:
1. **Local Tier (Merchant PC)**: Runs locally on XAMPP (Apache + PHP 8.2+ + MySQL). Provides **instant response times** (< 5ms) for barcode scanning, receipt printing, and cashier checkout, with zero dependency on internet connectivity.
2. **Cloud Tier (Supabase PostgreSQL)**: Serves as the central cloud source of truth, remote backups, owner analytics, and multi-branch aggregation.
3. **Single-Tenant Hardware Lock**: Configured via `TENANT_MODE=single`, locking the client machine strictly to one dedicated tenant account. The store cannot access other tenants or be exposed to central platform URLs.
4. **Outbox Synchronization Pattern**: Local transactions write to MySQL and a local `sync_outbox` table in the same transaction. A background worker continuously synchronizes pending records to Supabase over secure HTTPS.

## 1. XAMPP Local Installation on Windows

### 1.1 Requirements
- Windows 10 / 11 / Windows Server
- XAMPP with PHP 8.2 or PHP 8.3
- Git for Windows
- Composer 2.x

### 1.2 Enable Required PHP Extensions
Open `C:\xampp\php\php.ini` in a text editor and ensure the following extensions are enabled (remove the leading semicolon `;`):
```ini
extension=curl
extension=fileinfo
extension=intl
extension=mbstring
extension=openssl
extension=pdo_mysql
extension=pdo_pgsql
extension=pgsql
extension=zip
```
Restart Apache in the XAMPP Control Panel.

### 1.3 Deploy Codebase to XAMPP
Extract or clone the project into your web root:
```powershell
C:\xampp\htdocs\mde-pos
```

### 1.4 Apache VirtualHost Configuration (Recommended)
Open `C:\xampp\apache\conf\extra\httpd-vhosts.conf` and append:
```apache
<VirtualHost *:80>
    ServerName pos.local
    DocumentRoot "C:/xampp/htdocs/mde-pos/public"
    <Directory "C:/xampp/htdocs/mde-pos/public">
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
```

Open `C:\Windows\System32\drivers\etc\hosts` (as Administrator) and add:
```text
127.0.0.1 pos.local
```

## 2. Supabase Cloud Configuration

### 2.1 Retrieve Supabase Project Credentials
In your [Supabase Dashboard](https://supabase.com/dashboard):
1. Navigate to **Project Settings** → **API**:
   - `Project URL`: `https://xxxxxxxxxxxx.supabase.co`
   - `service_role key`: `eyJhbGciOi...` (Secret key with write access)
2. Navigate to **Project Settings** → **Database**:
   - Connection string under **Connection Pooling** (Transaction Pooler):
     - Host: `aws-0-eu-central-1.pooler.supabase.com`
     - Port: `6543` (Supabase Transaction Pooler recommended)
     - Database: `postgres`
     - Username: `postgres.your-project`
     - Password: `[YOUR-DB-PASSWORD]`

### 2.2 Supabase PostgreSQL Schema & Row-Level Security
Run this in the Supabase SQL Editor to establish tenant-scoped isolation:

```sql

    customer_name VARCHAR(255) NULL,
    items JSONB NOT NULL DEFAULT '[]',
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    synced_at TIMESTAMPTZ NOT NULL DEFAULT NOW()

-- Products Catalog Table

    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    tenant_id BIGINT NOT NULL,

-- Composite Indexes for High Performance
```

## 3. Local Machine Single-Tenant Locking

### 3.1 Environment Configuration (`.env`)
Configure the merchant PC's `.env`:
```env
APP_NAME="MDE-POS"
APP_ENV=production
APP_KEY=base64:...
APP_DEBUG=false
APP_URL=http://pos.local

# ── SINGLE-TENANT PC LOCK ──────────────────────────────────────────
# 'single' locks this PC strictly to one merchant.
# 'multi' is used on the cloud portal for subdomains.
TENANT_MODE=single
LOCKED_TENANT_ID="1"
LOCKED_TENANT_SLUG="nairobi-supermart"
TENANT_LICENSE_KEY="LIC-NAIROBI-2026-X992"

# ── LOCAL DATABASE (XAMPP MySQL) ──────────────────────────────────
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=pos_local
DB_USERNAME=root
DB_PASSWORD=

# ── CLOUD SUPABASE CONNECTION ─────────────────────────────────────
CLOUD_SYNC_ENABLED=true
SUPABASE_URL="https://your-project.supabase.co"
SUPABASE_KEY="eyJhbGciOi..."
SUPABASE_DB_HOST="aws-0-eu-central-1.pooler.supabase.com"
SUPABASE_DB_PORT=6543
SUPABASE_DB_DATABASE=postgres
SUPABASE_DB_USERNAME="postgres.your-project"
SUPABASE_DB_PASSWORD="your-secure-password"
SUPABASE_DB_SSLMODE=require
```

### 3.2 One-Click Machine Binding Command
To automatically lock the machine to a specific merchant account:
```powershell
php artisan tenant:bind nairobi-supermart --pull
```
**This command:**
1. Validates the tenant credentials.
2. Injects `TENANT_MODE=single`, `LOCKED_TENANT_ID`, and `LOCKED_TENANT_SLUG` into `.env`.
3. Flushes configuration cache.
4. Binds the login screen and POS routes so only staff from this store can sign in.
5. Automatically pulls product catalog data from Supabase.

## 4. Cloud Synchronization Engine

### 4.1 How Local Store-and-Forward Works
1. **Sales Checkout**: When a cashier completes a sale, it is saved locally to MySQL in `sales` and `sale_items`.
2. **Outbox Enqueue**: In the same transaction, a payload is written to `sync_outbox` with `status = 'pending'`.
3. **Cloud Dispatch**: The background sync daemon checks `sync_outbox` and sends batches of up to 50 records to Supabase over HTTPS.
4. **Confirmation**: Once Supabase responds `HTTP 200/201`, the record is marked `status = 'synced'` with a timestamp.

### 4.2 Manual Sync Command
```powershell
# Sync all pending sales and records
php artisan sync:cloud

# Sync and also pull newest catalog prices from Supabase
php artisan sync:cloud --pull
```

### 4.3 Automated Background Sync on Windows (Task Scheduler)
Create a scheduled task that flushes the outbox every minute:
1. Open **Windows Task Scheduler** (`taskschd.msc`).
2. Click **Create Basic Task** → Name: `MDE POS Cloud Sync`.
3. Trigger: **When the computer starts**.
4. Action: **Start a program**:
   - Program/script: `C:\xampp\php\php.exe`
   - Add arguments: `C:\xampp\htdocs\mde-pos\artisan sync:cloud`
5. In task Properties → **Triggers** → Edit:
   - Check **Repeat task every 1 minute** indefinitely.

## 5. Offline Operation & Disaster Recovery

### What happens when the internet drops?
- **Zero Interruption**: The cashier continues ringing sales, scanning barcodes, taking cash/card, and printing receipts at local speed.
- **Queued Records**: Transactions accumulate in local MySQL `sync_outbox` with `status = 'pending'`.
- **Automatic Recovery**: The instant internet connectivity resumes, the sync daemon automatically uploads all accumulated offline transactions in chronological order.

### What if the merchant's PC hard drive fails?
1. Install XAMPP on a replacement PC.
2. Clone/copy MDE-POS to `C:\xampp\htdocs\mde-pos`.
3. Run:
   ```powershell
   php artisan migrate --force
   php artisan tenant:bind {slug} --pull
   ```
4. All store products, prices, categories, and settings are immediately reconstructed from Supabase Cloud.
